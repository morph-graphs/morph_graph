What needs you?

Current problems only: failures of tasks that are still open and that nobody has claimed since, grouped by machine, experiment and cause. Failures that were later fixed, and jobs we cancelled, are not shown.

How many videos have a memory?

A memory is built once per video and model and shared by every question bank. Counted from the results dataset: a video counts when its memory folder holds the baseline's last file.

How many questions have an answer?

Per question bank, out of all its questions (summed over its videos). A question counts when the answers file in the results dataset has a response for it that is not an error.

Who is working right now?

Counts are board tasks; "other jobs" are our own Slurm jobs outside the board (smoke tests, ports), listed under Running now.

Is every machine's worker alive?

One row per machine. A machine can run several board workers, one per queue (on Nexus: tron, scavenger, vulcan-sailon, and Vatsal's); each writes a heartbeat about every minute, and one silent for over 30 minutes while it holds tasks is flagged. Done counts tasks finished in the last 24 hours.

Which tasks are where?

Every open task, in the board's priority order. Ready tasks go to the first machine listed for them that has a free slot and runs that baseline; a task that failed twice is held until someone fixes the cause and resets it.
