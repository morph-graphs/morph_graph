How many videos have a memory?

A memory is built once per video and model and shared by every question bank. Counted from the results dataset: a video counts when its memory folder holds the baseline's last file.

How many questions have an answer?

Per question bank, out of all its questions (summed over its videos). A question counts when the answers file in the results dataset has a response for it that is not an error.

How many questions has each method answered correctly?

One row per method, model and question bank; the bank "all" is every bank together. Scored by coord/sheet_update.py, the script that fills the results sheet, from the answer files in the results dataset: an answer counts only while its question's wording, options and gold letter are those of the current bank. Accuracy is right / answered, and its 95% interval is that script's: a percentile bootstrap over videos, Wilson when a run has one video. "Of all" counts every unanswered question as wrong. The floor is the same model answering the bank with no memory (the run's blind file), scored by the same rules.

Accuracy on answered questions of a partial run is not an estimate for the whole bank: the videos answered first are not a random sample, so compare runs only once both are complete, or read "Of all" as a lower bound. And a floor below chance is not a bug: questions that text-only models could answer were removed from this benchmark, so by construction the no-context floor can sit below chance.
